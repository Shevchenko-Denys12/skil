# Перевірка навички Wikipedia Interest

## 1. Встановлення

Потрібен Python 3.11+ і доступ до Wikipedia/Wikimedia API для першого запиту. Із кореня проєкту:

```sh
cd skills/wikipedia-interest
python3 -m venv /tmp/wikipedia-interest-venv
/tmp/wikipedia-interest-venv/bin/python -m pip install -r requirements.txt
```

У директорії навички є Python-код, інструкції, тести, приклад PDF/PNG і ліцензія вбудованого шрифту. Згенеровані під час запуску файли записуються **поза** директорією навички. Необхідні для PDF бібліотеки встановлюються з `requirements.txt`; скомпільованих виконуваних файлів у навичці немає.

## 2. Один запуск

Замініть `you@example.org` на власну контактну адресу або HTTPS-сторінку для `User-Agent`:

```sh
PYTHONDONTWRITEBYTECODE=1 /tmp/wikipedia-interest-venv/bin/python scripts/run.py \
  --topic 'Астрономія' --languages uk \
  --start 2023-01-01 --end 2024-12-31 \
  --contact 'you@example.org' \
  --cache-dir /tmp/wikipedia-interest-cache \
  --artifact-dir /tmp/wikipedia-interest-artifacts/my-astronomy
```

Команда повертає один компактний JSON у stdout. За успіху `status` дорівнює `complete`; поля `metrics` дають дві окремі оцінки тренду, узгодженість, надійність і точні URL джерел. У `artifacts` є абсолютні шляхи до `resolved_pages.json`, `series.json`, `analysis.json`, `chart.png`, `report.pdf`. PDF повинен мати `pdf_pages: 1`. На macOS `/tmp` може відображатися як `/private/tmp`. Папка `/tmp` тимчасова; для постійного зберігання задайте іншу директорію **поза** `skills/wikipedia-interest`.

Якщо відповідність статті не підтверджена, результат має `status: "needs_confirmation"`, `resolved_pages` із попередженнями та лише `resolved_pages.json`. PDF до уточнення статті не створюється. Передайте перевірену назву або URL через `--page 'pl=Назва статті'` й запустіть команду знову. Після підтвердження збережений файл можна передати як `--resolved /path/to/resolved_pages.json` замість `--topic` і `--languages`.

Для повторного аналізу без піка додайте `--exclude-peak 'uk=2024-09-01:причина виключення'`. Початкові метрики залишаються, а `alternatives` показує обидва перераховані сигнали й зміну висновку. Для власних порогів використайте `--criterion-json /path/to/criterion.json`. Дані кешуються за статтею, визначенням метрики й часовим блоком; повторні сумісні запити мають `cache.hits > 0`.

## 3. Що побачити

Кожен запуск `run.py`, включно з повтором після уточнення статті, потребує `--artifact-dir` без попередніх вихідних файлів. Команда відхиляє зайняті шляхи, зберігаючи старі результати. Використовуйте нову папку та спільний кеш; докладні правила — у [контракті](references/contract.md).

У [прикладі PDF](examples/astronomy-report.pdf) і [PNG](examples/astronomy-chart.png) показано реальні місячні перегляди української статті «Астрономія» за 2023–2024 роки. На момент перевірки 2026-09-27 одна команда зі збереженою перевіреною статтею й кешем повернула `cache.hits: 2`, `cache.misses: 0`, `pdf_pages: 1`, зміну між 2023 і 2024 роками **−36,1%**, стійкий тренд **−44,3%**, узгоджений висновок про спад і **середню** надійність через можливу сезонність. При новому живому запиті дані чи зіставлення статей можуть змінитися. Джерело: [стаття «Астрономія»](https://uk.wikipedia.org/wiki/%D0%90%D1%81%D1%82%D1%80%D0%BE%D0%BD%D0%BE%D0%BC%D1%96%D1%8F) та URL Pageviews усередині PDF.

Інші початкові приклади із завдання:

- «Порівняй інтервальне голодування в польській та чеській Wikipedia». Живий resolver обрав чеську статтю, але не підтвердив польську; потрібна її конкретна сторінка.
- «Порівняй вивчення англійської у вибраних мовних розділах». Спочатку уточніть коди мов і статті, які справді означають навчання англійської. Для припущення `pl`, `cs`, `uk` живий resolver не знайшов підтверджених відповідників статті `English as a second or foreign language`.

## 4. Метод, межі й перевірки

Місячні Pageviews для однієї підтвердженої статті на мову — **проксі уваги до теми**. Навичка порівнює дві рівні часові частини та обчислює стійкий Theil–Sen тренд на `log1p(views)`; напрям вважається переконливим лише за узгодження обох сигналів. Неповні місяці виключаються, пропуски не заповнюються нулями. Рівень надійності — практичне попередження про якість, а не статистичний інтервал. Детальні формули й пороги — у [методології](references/methodology.md).

Перегляди не доводять причину змін, географію читачів, попит на курс чи готовність платити. Одна стаття не охоплює всю широку тему; назви, редиректи, сезонність та зовнішні події можуть змінити інтерпретацію. Відповідь агента має відокремлювати дані від інтерпретації та пропонувати наступний тест гіпотези.

Офлайн-перевірка:

```sh
PYTHONDONTWRITEBYTECODE=1 /tmp/wikipedia-interest-venv/bin/python -m unittest discover -s tests -v
```

Перевірено 39 тестів: модульні граничні випадки, три початкові сценарії на **синтетичних API-фікстурах**, два follow-up, повторне використання кешу та односторінковий PDF. Живий приклад «Астрономія» додатково звірено із сирими Pageviews, відрендереним PDF і прогоном на швидкій моделі Codex Luna з інструментами. Перший агентський прогін склав хибний URL; після виправлення інструкції другий повернув точні URL з JSON. Деталі, промпт, виклики, токени, доступність Claude Haiku та спосіб перевірки AI-результатів — у [журналі етапу 6](references/stage-6-validation.md). Два непідтверджені живі приклади не зараховані як завершені PDF-звіти.

Подальші окремі ітерації з критеріями перевірки наведено в [черзі поліпшень](references/roadmap.md).
